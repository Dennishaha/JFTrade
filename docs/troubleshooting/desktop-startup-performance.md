# 桌面启动性能基准

本页记录桌面启动快路径的本地墙钟验收。CI 只验证结构性快路径和契约，不把墙钟阈值作为跨机器门禁。

## 2026-08-02 macOS ARM64

环境：macOS 27.0、Apple A18 Pro、8 GiB 内存，Go 1.26.5、Node 22+。正式包使用 `production,release_assets` 构建并通过 `codesign --verify --deep --strict`。

测量从启动正式 bundle 可执行文件开始，以进程日志出现 `desktop window ready` 和 `desktop API ready` 为终点；外部采样间隔为 50 ms。冷启动每次使用独立临时 settings 目录，强制写入一个新的 Yahoo helper 摘要缓存；热启动复用正式产品当前摘要缓存，每次之间留出 3 秒回收时间。

## 复测方法

先构建当前生产资源和正式包：

```bash
pnpm run build:frontend-assets
pnpm run build:yfinance-sidecar
JFTRADE_DESKTOP_PREPARED=1 node scripts/build-desktop.mjs darwin-arm64
```

开发态先运行一次形成原生 bundle 缓存，再连续运行 5 次 `pnpm run desktop:dev`。正式包冷启动必须使用独立临时 settings 目录，不能删除真实产品缓存来造冷启动；热启动直接复用当前摘要目录，并在每次退出后确认 6699 和 helper 动态端口已经释放。
